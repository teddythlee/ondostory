# 기획 단계

초안 쓰기 전에 짧은 콘텐츠 브리프를 만든다(각 한 줄):

- 타깃 독자 (누가, 어떤 상황)
- 핵심 문제
- 검색 의도 ("이걸 누가, 어떤 말로 검색?")
- 직접적인 답 (결론부터)
- 온도스토리 고유 가치 (남들 글에 없는 것)
- 1차 키워드
- 보조 키워드
- 필요한 근거 (공식 출처·데이터·경험)
- 아웃라인 (소제목 순서)
- FAQ 후보
- 내부 링크 기회 (§6.5 — 대상 슬러그 확인된 것만)
- 원하는 독자 행동 (CTA)

아웃라인은 **핵심 질문에 초반부터 답하고**, 실용 필수 → 세부 순으로 간다(가이드 §2).
경험이 들어갈 자리는 미리 표시해 둔다 → 작성 단계에서 `[[경험 추가: …]]`로 비운다.
