# 기획 단계

초안 쓰기 전에 짧은 콘텐츠 브리프를 만든다(각 한 줄):

- 타깃 독자 (누가, 어떤 상황)
- 핵심 문제
- 검색 의도 ("이걸 누가, 어떤 말로 검색?")
- 주검색어 1개와 근거 (GSC 또는 구글·네이버 자동완성에서 실제 확인한 문구)
- 현재 검색결과의 공통 약속 / 비어 있는 정보 (주검색어로 직접 비교)
- 직접적인 답 (결론부터)
- 온도스토리 고유 가치 (남들 글에 없는 것)
- 1차 키워드
- 보조 키워드
- 필요한 근거 (공식 출처·데이터·경험)
- 아웃라인 (소제목 순서)
- FAQ 후보
- 내부 링크 기회 (§6.5 — 대상 슬러그 확인된 것만)
- 원하는 독자 행동 (CTA)
- 제목 후보 3개 (`주검색어 + 서로 다른 구체 효익 하나`)와 최종 선택 이유
- 검색결과용 `meta_title` 압축본 + 클릭 전 미리보기인 `meta_description`

아웃라인은 **핵심 질문에 초반부터 답하고**, 실용 필수 → 세부 순으로 간다(가이드 §2).
경험이 들어갈 자리는 미리 표시해 둔다 → 작성 단계에서 `[[경험 추가: …]]`로 비운다.
제목은 `총정리`·과장어로 세게 만드는 대신, 본문이 실제로 증명하는 구체 효익 하나로 클릭 이유를 만든다(가이드 §3 CTR 프리플라이트).
