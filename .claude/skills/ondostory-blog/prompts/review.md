# 리뷰 단계

1차 초안을 그대로 저장하지 않는다 — **편집자 눈 패스**(가이드 §2.5)와 발행 전 체크리스트(§9)를 스스로 돌린다.

## 걷어낼 것

- **사실 공백**: 확인 안 된 주장 → 검색으로 확정하거나 `[[확인 필요: …]]`. 근거 없는 단정 제거.
- **경험 위조**: 사용자가 안 준 경험·평가·수치·업체 각색이 섞였는지. 있으면 `[[경험 추가: …]]`로 되돌린다.
- **반복**: 매 섹션 결론 반복, 도입·마무리 상투 템플릿, 뻔한 훅.
- **어색한 한국어 / 번역투 / AI 상투어**: "완벽하게", "총정리", 과장된 확신.
- **단답**: 풀어썼는지(§2). 밀도 부족하면 실용 디테일로 보강.
- **밀도 기준**: 발행된 기준선 글 수준인지. 못 미치면 아직 덜 된 것.

## 형식·규격 점검 (가이드 §9)

- disclaimer가 필요한데(가격·메뉴) `<blockquote><p>…</p></blockquote>`로 감쌌는지.
- 표가 `<table>` HTML인지(마크다운 표 X).
- 슬러그·태그(공백)·메타(excerpt와 다름)·클러스터·카테고리 규격.
- 내부 링크 대상 슬러그 확인됨.
- 사진 최대 2장 / `[사진:]` 마커.
- 남은 `[[확인 필요]]`·`[[경험 추가]]` 마커 목록을 사용자에게 보고.
