# SEO 단계

규격 원본은 가이드 §3(제목)·§4(메타)·§5(태그)·§6(클러스터)·§6.5(내부링크)·§7(카테고리). 여기선 산출 체크만.

## 산출물

- **제목**(§3): 검색어를 앞에, 영리함보다 명확함. 60자 내외.
- **슬러그**: kebab-case, 6단어 이하, 영문 소문자·숫자·하이픈. 후보만 제안(확정은 사람). 배포된 슬러그는 바꾸지 않음.
- **메타 디스크립션**(§4): 140~160자. **excerpt와 동일 금지**(복붙하면 인제스트 400). 자연스럽게 1차 키워드 포함.
- **1차 키워드 1개 + 보조 키워드 몇 개**(§5). 키워드 스터핑 금지.
- **소제목(H2/H3)**: 문장형, 검색 의도 반영.
- **태그** 4~6개(§5): **공백 표기**(하이픈 금지).
- **클러스터**(§6): clusters 테이블의 존재하는 key 1개.
- **카테고리**(§7): `후기` / `정보`.
- **내부 링크**(§6.5): **대상 슬러그를 실제로 확인한 것만** 추천(같은 클러스터 우선). 확인 못 하면 넣지 않는다.
- **외부 링크**: 공식·1차 출처 우선.
- **FAQ**: 유용할 때만(`templates/faq.md`·`schema.json`).
- **이미지 alt**(§8): 무엇을 보여주는지 구체적으로. 실제 사진 없으면 `[사진:]` 마커.

🚫 추정 검색량을 측정값처럼 쓰지 않는다. 없는 내부 링크·출처를 지어내지 않는다.
