# 중심축 설계: 미국 렌트·이사(housing) — 2026-10-01

## 왜 이 축인가 (데이터)

AdSense가 두 번 "가치 없는 콘텐츠"로 반려했다. 글 단위 품질(길이·경험 신호·중복)은 이미
사내 스캐너 기준으로 포화 상태였고, 남은 문제는 **주제가 7개로 흩어져 어느 축에서도 두텁지
않다**는 구조였다. 그런데 검색 데이터에는 단 하나의 뚜렷한 수요가 있다.

최근 28일(8/31~9/28) 검색어 — 유홀 계열 한 묶음:

인접 수요(이사 전 짐 처분)도 이미 작동한다 — `us-secondhand-marketplace-apps`:
미국 당근/당근마켓/중고나라/중고거래 계열 **125 노출, 3 클릭, 최고 4위**.

핵심 진단: **5개 검색 의도(전반·가격·사이즈·렌트방법·용어)를 글 한 편이 모두 받고 있고,
6위권인데 클릭이 거의 없다.** 의도별로 분화된 글이 없어서 클릭이 새는 구조다.

## 신규 글 — 증명된 수요 순서

각 글은 "받을 검색 의도"를 하나만 정면으로 받는다. 제목은 그 의도의 말투를 그대로 쓴다.

1. **유홀 트럭 사이즈 고르는 법** — 받을 의도: `유홀 트럭 사이즈`(20노출·5.7위)
   10/15/20/26피트 적재 기준, 방 수·가구 기준 환산, 10피트로 실제 옮겨본 분량과의 대조.
   실경험 앵커 있음(10피트). 나머지 사이즈는 공식 제원으로 보강하고 추정은 추정이라 밝힌다.

2. **유홀 렌트 총비용** — 받을 의도: `유홀 트럭 가격`(21노출·6.2위)
   일 기본료 + 마일당 요금 + 환경수수료 + 보험(SafeMove 등) + 연료 실비. 실제 영수증 기준
   총액과 견적 화면 금액의 차이. 편도(one-way) vs 왕복(in-town) 요금 체계 구분.

3. **유홀 예약부터 반납까지** — 받을 의도: `유홀 트럭 렌트`(45노출·6.0위), `u-haul 뜻`(21노출)
   예약·픽업(앱 체크인, 면허·카드), 적재 장비(dolly·패드), 주유 규칙, 반납 사진, 연장·취소.
   용어 설명(U-Haul이 무엇인지)을 도입부에 두어 `u-haul 뜻` 의도도 같이 받는다.

4. **이사 전 짐 처분 순서** — 받을 의도: 중고거래 계열(125노출·4위) 확장
   기존 중고거래 앱 글을 "처분 전략"으로 승격: 팔 것/기부할 것/버릴 것 분류, Karrot·OfferUp
   실제 거래 경험, 기부 영수증(세금), 대형 폐기물 수거 신청.

5. **편도 장거리 이사** — 받을 의도: 주간 이동 이사
   경험이 없으면 **쓰지 않는다.** 조사만으로 쓰면 지금까지 반려된 유형의 글이 된다.

## 내부 링크 규칙 (구조 작업 — 내가 할 몫)

- 입구 글(유홀 후기) 본문에 1~3번 글로 가는 링크를 단계 순서대로 배치
- 각 하위 글은 입구 글과 바로 앞·뒤 단계 글로 역링크 (고아 글 금지)
- 이사 타임라인 순서로 서로 연결: 집 유형 선택 → 렌트 계약 → 짐 처분 → 트럭 사이즈 →
  총비용 → 예약·반납 → 유틸리티 개통 → 주소 변경 → 퇴거·디파짓
- `/guides/housing` 허브의 `meta_description`이 비어 있다 — 채운다
- `us-secondhand-marketplace-apps`를 housing으로 재배치할지 결정(쇼핑 맥락도 유효해서
  클러스터 이동 대신 양쪽에서 링크하는 방안도 가능)
